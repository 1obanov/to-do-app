# To-Do List Application
>Minimalist to-do app built with plain JavaScript.

### Preview

Explore the live demo of the **To-Do App** [here](https://1obanov.github.io/to-do-app/).


### Installation
```
# Install dependencies
npm install

# Run for development
gulp dev

# Serve with reload at localhost:3000
gulp

# Run for production
gulp dist
```
